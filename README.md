# trainYourself1.1

A historical learning repository from the early stages of the MountainBridge engineering journey.

## Why this repository exists

This repository is intentionally preserved as **engineering history** rather than presented as a current production-style project. It shows the progression from hands-on experimentation toward the more structured engineering labs and case studies in this portfolio.

## How to read it

Use this repository to understand the learning trail, not as the primary evidence of current engineering practice.

For current portfolio work, start with:

- [`MountainBridges`](https://github.com/MountainBridge/MountainBridges) — engineering casebook and system-design narrative
- `KafkaEventPlatform` — event-driven architecture and Kafka fundamentals
- `PostgreSQLEngineeringLab` — relational data engineering and performance thinking
- `MongoDBEngineeringLab` — document-data modeling and operational trade-offs
- `AIEvaluationAgentLab` — AI evaluation, agents and evidence-driven testing

## Portfolio standard

Current projects follow a consistent pattern:

**problem → user journey → engineering constraints → design choices → implementation → tests → failure modes → evidence**

That distinction is intentional: modernization means making the portfolio coherent without rewriting away its history.
